# 📚 Book Tracker - Трекер прочитанных книг

Приложение с графическим интерфейсом для учёта прочитанных книг, созданное на Python с использованием библиотеки Tkinter.

## 📖 Описание программы

Book Tracker - это desktop-приложение, которое позволяет:

- ✅ Добавлять книги с указанием названия, автора, жанра и количества страниц
- 📊 Просматривать список всех добавленных книг в удобной таблице
- 🔍 Фильтровать книги по жанру и минимальному количеству страниц
- 📈 Смотреть подробную статистику (общее количество книг, страниц, распределение по жанрам, самая толстая и тонкая книга)
- 💾 Сохранять данные в JSON-файл и загружать их при следующем запуске
- 🗑️ Очищать весь список книг с подтверждением

## 🎯 Цель проекта

Создание удобного инструмента для читателей, которые хотят систематизировать свои прочитанные книги и отслеживать прогресс чтения.

1. **Убедитесь, что Python установлен**
   ```bash

или

bash

📝 Примеры использования
Пример 1: Добавление книги
В поле "Название книги" введите: Мастер и Маргарита

В поле "Автор" введите: Михаил Булгаков

Выберите жанр: Роман

В поле "Количество страниц" введите: 480

Нажмите кнопку "ДОБАВИТЬ КНИГУ"

Пример 2: Фильтрация книг
Ситуация: Хотите найти все фэнтези-книги с более чем 300 страницами

В блоке "Фильтрация книг" выберите жанр: Фэнтези

В поле "Страниц больше чем:" введите: 300

Нажмите "ПРИМЕНИТЬ ФИЛЬТР"

Программа покажет только книги, соответствующие критериям

Пример 3: Просмотр статистики
Ситуация: Хотите узнать свою читательскую статистику

Добавьте несколько книг (минимум 1)

Нажмите кнопку "СТАТИСТИКА"

Появится окно с информацией:

Общее количество книг

Общее количество прочитанных страниц

Среднее количество страниц на книгу

Распределение по жанрам

Самая толстая и самая тонкая книга

Пример 4: Сохранение и загрузка данных
Сохранение:

Добавьте книги в трекер

Нажмите "СОХРАНИТЬ В JSON"

Файл books.json создастся в папке с программой

Загрузка при следующем запуске:

Программа автоматически загрузит данные из books.json при старте

Также можно нажать "ЗАГРУЗИТЬ ИЗ JSON" для ручной загрузки

🛠️ Возможные ошибки и их решение
Ошибка	Причина	Решение
"Заполните название книги и автора!"	Пустые поля	Заполните все обязательные поля
"Количество страниц должно быть числом!"	В поле страниц введены буквы	Введите только цифры
"Файл books.json не найден!"	Нет сохранённого файла	Сначала сохраните данные кнопкой "СОХРАНИТЬ В JSON"
"Файл повреждён!"	JSON-файл имеет неверный формат	Удалите books.json и создайте новый сохранением

  }
]
